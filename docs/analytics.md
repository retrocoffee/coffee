# Яндекс Метрика

Счётчик: **114095245**, сайт: https://retrocoffee.github.io/coffee/.
Номер задаётся в `config/analytics.json`. Значение `null` отключает подключение
и возвращает строгую CSP без внешних запросов. После изменения нужна публикация.

Bootstrap в `public/analytics.js`, он загружается без inline-кода и асинхронно
подключает официальный tag.js. Вебвизор, карта кликов, автоматическое отслеживание
ссылок и hash-переходов выключены. Обычная статистика посещений и точности отказов
включена. Ecommerce и пользовательские идентификаторы сайтом не передаются.
Информация о сервисе добавляется в «О кофейне» при включённом счётчике.

## Цели

В аккаунте Яндекс Метрики откройте счётчик → Настройки → Цели → Добавить цель.
Тип: **JavaScript-событие**, условие: совпадает. Создайте следующие идентификаторы:

| Название | Идентификатор | Параметры |
|---|---|---|
| Открытие раздела | `category_open` | `section`: ID раздела |
| Переход из карусели к напитку | `carousel_item` | `item`: ID позиции |
| Переход к отзыву | `review_click` | — |
| Открытие окна соцсетей | `socials_open` | — |
| Переход в соцсеть | `social_click` | — |
| Открытие сведений о кофейне | `about_open` | — |

Код отправляет эти события, но не создаёт определения целей в аккаунте:
доступ к управлению вашим аккаунтом Яндекса ему не предоставлен.
Автолистание карусели не считается переходом к напитку, раскрытие состава
не считается открытием раздела. Пользовательский текст и поля реквизитов
в параметры целей не включаются.

## Проверка

Откройте опубликованный сайт из нового окна браузера, затем проверьте получение
данных в интерфейсе своего счётчика. Для отладки целей используйте параметр
`?_ym_debug=1` согласно документации Яндекса. Блокировщик рекламы может блокировать
Метрику. При сбое/блокировке счётчика сайт продолжает работать.

Автоматическая проверка использует заглушку tag.js и не отправляет тестовые
посещения в рабочий счётчик. Содержимое отчётов и право владения счётчиком
проверяются в аккаунте владельца.

Документация: https://yandex.ru/support/metrica/ru/code/install-counter-csp
и https://yandex.ru/support/metrica/ru/general/goal-js-event.
