# Проверка безопасности и оптимизации — 30 октября 2026

Проверены исходники сайта и Telegram-редактора, текущие отслеживаемые файлы,
зависимости Python, конфигурация публикации и работа локальной сборки в Chromium.
Продакшен Telegram/Cloudflare не атаковывался, пользовательские данные не изменялись.
Это проверка кода и контролируемые тесты, а не гарантия отсутствия всех уязвимостей.

## Найдено и исправлено

- `pip-audit` сообщил об известных уязвимостях Pillow 12.3.0 и рекомендовал
  13.0.0. Зависимость обновлена; повторный аудит: `No known vulnerabilities found`.
- Добавлена CSP через HTML meta: скрипты только с собственного origin, запрет
  сетевых запросов приложения, объектов, отправки форм и подмены base URL.
  Inline-стили разрешены для существующей карусели; inline-скрипты запрещены.
- Добавлена политика `no-referrer` для внешних переходов.
- Checkout в процессе публикации больше не сохраняет Git credentials.
- Сборка создаёт WebP-копии изображений до 96 и 320 пикселей; браузер выбирает
  подходящую через srcset. Оригиналы и история загрузок сохраняются.
- Основной шрифт загружается заранее.

## Результаты

- 114 автоматических тестов прошли с Pillow 13.0.0: в том числе доступ только
  разрешённых Telegram ID в личном чате, привязка callback к владельцу,
  HTML-экранирование, безопасные пути картинок, лимиты загрузок и пикселей,
  удаление EXIF, конфликтующие правки и восстановление после отказа Git push.
- Поиск распространённых форматов GitHub/Telegram токенов и приватных ключей
  в текущих отслеживаемых файлах: совпадений нет. Вся история Git не сканировалась.
- Browser-тесты подтверждают блокировку inline-скриптов, обработчиков событий,
  подмены base и outbound fetch; диалоги и карусель работают.
- Локальный первый экран: Chromium, 390×844, DPR 2, новый контекст,
  reduced motion, без эмуляции медленной сети. Размер ресурсов без HTML,
  сумма PerformanceResourceTiming.encodedBodySize: **489 677 → 239 917 байт**
  (−51%). Число запросов: 11 → 11. Наблюдавшийся CLS: 0.0213 → 0.
  Это лабораторный замер, не полевые Core Web Vitals и не время реальной загрузки.
- Нет внешних запросов страницы, установленных ею cookies, ошибок JavaScript
  и неуспешно декодированных изображений в этом сценарии.
- Проверены 280/390/1440 px, свайпы, клавиатура, открытие разделов, ссылки на
  позиции, 6-секундная пауза и возобновление автолистания после ручного режима.

## Границы

Не проверялись права участников GitHub, настройки защиты веток, значения secrets,
HTTP-заголовки и TLS живого домена. GitHub Pages не позволяет этому проекту
назначать произвольные HTTP-заголовки. `frame-ancestors` нельзя обеспечить meta-CSP:
защита от встраивания в чужой iframe требует заголовка на поддерживающем его хостинге
или прокси. Такая защита здесь не заявляется.

Повторная проверка: `npm run check`; аудит зависимости: `pip-audit -r bot/requirements.txt`.
