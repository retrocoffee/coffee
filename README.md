# РЕТРОКОФЕ

Статический сайт кофейни: загруженные фотографии зёрен в хаотичном порядке с разными размерами, поворотами и размытием, плавно покачивающиеся в воздухе около своих мест, минималистичная вывеска с объёмными буквами и тёплой подсветкой на графитовом фоне, меню с перелистыванием страницы. Все ресурсы хранятся локально; внешние сервисы при просмотре не требуются.

## Локальный запуск

```sh
npm run check
npm start
```

Открыть http://localhost:4173. Сборка и установка npm-пакетов не требуются.

## GitHub Actions → GitHub Pages

Workflow `.github/workflows/deploy.yml` проверяет сайт и публикует каталог `public` после push в `main`. Владелец репозитория должен один раз выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем запустить **Actions → Publish RetroCoffe → Run workflow**, если первый запуск произошёл до настройки Pages.

Ожидаемый адрес после успешного деплоя: https://retrocoffee.github.io/coffee/.

## Изменение меню

Позиции, объёмы, граммовка и цены находятся в `public/index.html`. Сейчас это пробные данные. Дизайн — `public/style.css`, навигация — `public/app.js`, фотографии зёрен — `public/assets/grains/`, их расположение — `public/index.html`.

Есть управление стрелками клавиатуры, свайпом, кнопками; поддержка `prefers-reduced-motion`. На телефоне разворот меню становится вертикальным.
