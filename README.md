# РЕТРОКОФЕ

Минималистичный сайт меню: белый фон, чёрный текст и красные разделители. Шесть раскрывающихся категорий: сезонное меню, кофе, не кофе, холодное с молоком, очень холодные напитки и бабл напитки. Позиции, объёмы, цены и добавки перенесены из документа «менюА5.docx».

## Локальный запуск

```sh
python3 -m pip install -r bot/requirements.txt
npm run check
npm start
```

Открыть http://localhost:4173. Python-зависимость Pillow обрабатывает картинки, загруженные через Telegram. HTML меню собирается автоматически.

## Публикация

GitHub Actions в `.github/workflows/deploy.yml` проверяет сайт и публикует `public` на GitHub Pages при push в `main`.

Адрес: https://retrocoffee.github.io/coffee/.

## Изменения

Меню и цены — `data/menu.json`, сгенерированная страница — `public/index.html`, оформление — `public/style.css`, логотип — `public/assets/logo.svg`. Разделы работают через нативные `details` и `summary`, в том числе с клавиатуры и без JavaScript. Скрипт `public/app.js` обеспечивает открытие одной категории за раз в старых браузерах.

Manrope — SIL Open Font License, лицензия в `public/assets/MANROPE-LICENSE.txt`.

## Анимация логотипа

В шапке используется `public/assets/logo-animated.svg`: вращается только центральная кружка, бордовая основа остаётся неподвижной. SVG сохраняет прозрачность и прежний размер логотипа. Полный цикл занимает 8 секунд с паузой между оборотами; скорость задаётся в `.logo-cup` параметром `animation: cup-turn 8s ...`. При системной настройке уменьшения движения анимация выключена. Статичный `public/assets/logo.svg` продолжает использоваться как иконка вкладки.

## Карусель позиций

### Небольшие украшения к Хэллоуину

В `config/seasonal.json` параметр `halloween: true` включает два украшения: бордовую тыкву с вырезанными глазами и улыбкой вместо плюса у закрытого раздела «ОСЕНЬ ВКУСНО» и привидение из пенки на тыквенном рафе в карусели. У открытого раздела остаётся обычный минус. Картинка рафа в меню, состав карусели, названия и цены сохраняются; картинка, выбранная администратором для карусели, имеет приоритет над праздничной. Для возврата обычного вида установите `halloween: false` и сохраните в `main`: сборка вернёт обычный плюс и прежнюю картинку рафа.

Подборка редактируется в Telegram: **/start → Карусель** или нижняя кнопка **Карусель**. Доступны добавление из меню, изменение порядка, скрытие, удаление из подборки, отдельные картинки и описания. Нажмите **Сохранить подборку → Сохранить и опубликовать** для применения. Название, цена и объём связаны с меню; отдельные картинки карусели не меняют иконки позиций. [Подробная инструкция](bot/README.md#карусель).

Карусель под логотипом использует позиции из `data/menu.json`: название, актуальную цену и первый доступный объём. Настройка подборки — `data/carousel.json`, где `section`, `group`, `item` ссылаются на ID в меню, а `image` задаёт путь к изображению в `public/assets/products/` (SVG, PNG, WebP, JPG или AVIF) либо к сохранённой картинке в `public/assets/menu-images/`. В подборке 11 позиций. К исходным шести добавлены глинтвейн, сбитень, тыквенный раф, имбирный какао и коктейль «Орео» с цветными акварельными иллюстрациями в едином стиле.

Генератор `scripts/build-menu.py` обновляет карточки при каждой публикации, включая сохранение через Telegram. Скрытые разделы, удалённые позиции и позиции без доступной цены пропускаются. Изменения оформления сохраняются при следующем редактировании меню.

Карусель показывает одну позицию по центру, соседние — полупрозрачные. Интервал и длительность плавного сдвига задаются в `public/app.js`. После ручного перелистывания стрелкой, свайпом или клавишами ←/→ автолистание приостанавливается и возобновляется через 10 секунд без новых ручных переключений. Каждое новое перелистывание запускает отсчёт заново; удержание свайпа не расходует время ожидания. Кнопки воспроизведения нет. После ручного переключения таймер работает и при оставленном на стрелке указателе или фокусе. В скрытой вкладке, за пределами экрана и при открытом окне движение приостановлено. При системной настройке уменьшения движения автолистание выключено, а ручные переходы выполняются без анимации.


## Картинки позиций

Перед каждой позицией показана небольшая монохромная иконка из `public/assets/menu-icons/`. Своя картинка загружается через Telegram: **раздел → группа → позиция → Картинка → Добавить/Заменить → отправить фото или файл → Сохранить**. Поддерживаются JPG, PNG и WebP до 5 МБ и 16 мегапикселей. PNG/WebP с прозрачностью отправляйте как файл. Картинка выбранной позиции также используется в карусели, если она входит в подборку.

Бот сохраняет нормализованный WebP до 640×640 без метаданных в `public/assets/menu-images/`, а ссылку — в поле `image` позиции в `data/menu.json`. Имя файла зависит от содержимого, поэтому замена не кешируется под старым адресом. **Стандартная иконка** сбрасывает свою картинку. Старые файлы сохраняются для восстановления истории. Цена, текст и CSV-импорт не сбрасывают картинки. Новые позиции сразу получают стандартную иконку.

## Генерация картинок в Telegram

**Позиция → Картинка → Сгенерировать по описанию**: введите описание или используйте текст позиции, подтвердите генерацию, посмотрите результат и нажмите **Сохранить**. После создания позиции доступна прямая кнопка **Картинка новой позиции**. Генерация не меняет цены и описание; картинка сохраняется в прежней истории меню.

Для подключения добавьте Repository secrets `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`, затем перезапустите workflow `Telegram menu admin`. В **/start → Настройки генерации** или через нижнюю кнопку **Генерация** выбираются цветность, стиль и модель (FLUX.1 schnell / SDXL Lightning). По умолчанию — цветная иллюстрация на белом фоне. Сохранённые настройки общие для администраторов и хранятся в `config/generation.json`, отдельно от меню и оформления. Смена параметров не запускает генерацию; готовые картинки меняются только после сохранения нового результата. На Workers Free действует ежедневная бесплатная квота; при её исчерпании запросы останавливаются. На Workers Paid использование сверх квоты может тарифицироваться. Без секретов ручная загрузка и редактирование меню доступны. [Настройка, предпросмотр и ограничения](bot/README.md#генерация-по-описанию).
