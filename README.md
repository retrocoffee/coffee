# РЕТРОКОФЕ

Минималистичный сайт меню: белый фон, чёрный текст и красные разделители. Шесть раскрывающихся категорий: сезонное меню, кофе, не кофе, холодное с молоком, очень холодные напитки и бабл напитки. Позиции, объёмы, цены и добавки перенесены из документа «менюА5.docx».

## Локальный запуск

```sh
python3 -m pip install -r bot/requirements.txt
npm run check
npm start
```

Открыть http://localhost:4173. Python-зависимость Pillow обрабатывает картинки, загруженные через Telegram. HTML меню собирается автоматически.

## Публикация

GitHub Actions в `.github/workflows/deploy.yml` проверяет сайт и публикует `public` на GitHub Pages при push в `main`.

Адрес: https://retrocoffee.github.io/coffee/.

## Изменения

Меню и цены — `data/menu.json`, сгенерированная страница — `public/index.html`, оформление — `public/style.css`, логотип — `public/assets/logo.svg`. Разделы работают через нативные `details` и `summary`, в том числе с клавиатуры и без JavaScript. Скрипт `public/app.js` обеспечивает открытие одной категории за раз в старых браузерах.

Manrope — SIL Open Font License, лицензия в `public/assets/MANROPE-LICENSE.txt`.

## Меню через Telegram

[Настройка и инструкция бота](bot/README.md). Источник меню — `data/menu.json`; меняйте оформление независимо от него. `npm start` и GitHub Actions собирают HTML из актуальных данных автоматически. Редактирование меню в сгенерированном HTML не сохраняется после сборки.

## Карусель позиций

Карусель под логотипом использует позиции из `data/menu.json`: название, актуальную цену и первый доступный объём. Настройка подборки — `data/carousel.json`, где `section`, `group`, `item` ссылаются на ID в меню, а `image` задаёт путь к изображению в `public/assets/products/` (SVG, PNG, WebP, JPG или AVIF). Сейчас добавлено шесть иллюстраций напитков.

Генератор `scripts/build-menu.py` обновляет карточки при каждой публикации, включая сохранение через Telegram. Скрытые разделы, удалённые позиции и позиции без доступной цены пропускаются. Изменения оформления сохраняются при следующем редактировании меню.

Автодвижение зациклено. Стрелки, свайп и клавиши ←/→ позволяют листать вручную; кнопка под карточками включает и выключает движение. При наведении мыши или фокусе клавиатуры движение приостанавливается. Для системной настройки уменьшения движения автоматическая анимация изначально выключена.


## Картинки позиций

Перед каждой позицией показана небольшая монохромная иконка из `public/assets/menu-icons/`. Своя картинка загружается через Telegram: **раздел → группа → позиция → Картинка → Добавить/Заменить → отправить фото или файл → Сохранить**. Поддерживаются JPG, PNG и WebP до 5 МБ и 16 мегапикселей. PNG/WebP с прозрачностью отправляйте как файл. Картинка выбранной позиции также используется в карусели, если она входит в подборку.

Бот сохраняет нормализованный WebP до 640×640 без метаданных в `public/assets/menu-images/`, а ссылку — в поле `image` позиции в `data/menu.json`. Имя файла зависит от содержимого, поэтому замена не кешируется под старым адресом. **Стандартная иконка** сбрасывает свою картинку. Старые файлы сохраняются для восстановления истории. Цена, текст и CSV-импорт не сбрасывают картинки. Новые позиции сразу получают стандартную иконку.

## Генерация картинок в Telegram

**Позиция → Картинка → Сгенерировать по описанию**: введите описание или используйте текст позиции, подтвердите генерацию, посмотрите результат и нажмите **Сохранить**. После создания позиции доступна прямая кнопка **Картинка новой позиции**. Генерация не меняет цены и описание; картинка сохраняется в прежней истории меню.

Для подключения добавьте Repository secret `OPENAI_API_KEY` и перезапустите workflow `Telegram menu admin`. API оплачивается отдельно; по умолчанию используется `gpt-image-1-mini`. Без ключа ручная загрузка и редактирование меню доступны. [Настройка, предпросмотр и ограничения](bot/README.md#генерация-по-описанию).
